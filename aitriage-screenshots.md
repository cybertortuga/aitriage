# aitriage-screenshots

## Обзор
Нужно запустить web-режим AITriage и подготовить набор презентационных скриншотов по запросу Макса. Уточнение от Андрея: основной набор делаем из `Simple` режима, из `Advanced` режима нужны только несколько дополнительных обзорных кадров. Все финальные скриншоты должны быть сняты в русском интерфейсе (`RU`). Файлы скриншотов нужно назвать по смыслу, чтобы их можно было сразу использовать в презентации.

- стартовый экран с отчетом;
- способ запуска и пустой стартовый интерфейс;
- выбор проекта;
- добавление ИИ;
- запуск сканирования;
- экран с готовым prompt-plan.

Работа не предполагает изменений кода приложения. Основной результат: проверенный локальный web UI и PNG-скриншоты в `artifacts/aitriage-screenshots-20260708/` с понятными пронумерованными именами по порядку из сообщения Макса. Черновые англоязычные кадры не засчитываются и должны быть перезаписаны русскоязычными. Правая панель `ПРОЕКТЫ` скрывается на кадрах, где она не является смыслом кадра; на `03` она оставлена для выбора проекта, на `05` оставлен только scan-progress без длинного списка проектов.

## Затронутые файлы и области
- `aitriage-screenshots.md` — рабочий план и финальный отчет.
- `README.md`, `Makefile`, `docker-compose.yaml`, `Dockerfile` — только чтение: подтверждение штатного запуска web-режима.
- `cmd/aitriage/web.go`, `internal/server/server.go`, `internal/server/handlers/auth_handlers.go` — только чтение: маршруты web/API, health, auth, scan, runway и agent prompt.
- `web/package.json`, `web/src/App.tsx`, `web/src/components/Layout.tsx`, `web/src/components/LoginPage.tsx`, `web/src/pages/SimpleDashboardPage.tsx`, `web/src/components/admin/SystemConfigTab.tsx`, `web/src/services/api.ts`, `web/src/services/securityService.ts` — только чтение: UI-флоу, экраны, настройки ИИ, scan panel, prompt generation.
- `artifacts/aitriage-screenshots-20260708/` — новые PNG-файлы скриншотов для презентации.

## Риски и зависимости
- Нужен локальный Docker.
- Нужен свободный порт `8080`.
- Для реального AI-runway отчета нужны LLM-переменные окружения; для презентационного prompt-plan можно использовать встроенный `agent-prompt`, который строится сервером из finding без внешнего LLM.
- Существующие незакоммиченные изменения в репозитории не относятся к этой задаче и не должны быть изменены.
